The measurement protocol, by version

This is the entry point for the EcoCompute measurement protocol — the rules that make an energy number a measurement rather than a headline. The current spec is Protocol v1.1.

Protocol v1.1 (current) — the complete methodology: NVML on-device power sampling at ≥ 10 Hz, a same-session FP16 baseline for every non-FP16 arm, 256-token / 10-iteration measurement windows, thermal and cooldown rules, and honest failure states.
  • Read it here: ecocompute-protocol-v1.1 (rendered spec)
  • Cite it by DOI, not URL: version 10.5281/zenodo.22958675 · concept 10.5281/zenodo.22958674 (Zenodo archive is canonical; this page and the rendered spec are conveniences)
  • Machine-checkable half: the report schema and the semantic validator — the schema checks structure, the validator checks the protocol's MUSTs
